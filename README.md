# RedDodge
My first game I made using godot. You avoid enemies and die on contact with enemies.

## Features:
1. You play as a red bacteria that is trying to avoid antibiotics and survive.
2. You need to dodge the antibiotics.
3. A scoring system that shows the amount of antibiotics that you dodged.

## Why I built it:
I built it to use my newly acquired knowledge about gdscript and godot.
